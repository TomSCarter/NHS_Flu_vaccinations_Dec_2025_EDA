# Community Pharmacy Adult Seasonal Influenza Vaccination Service Current Report – Pharmacy Contractors

An exploratory data analysis (EDA) of the NHS Community Pharmacy Adult Seasonal Influenza Vaccination Service for the month of December 2025.

## Project Overview

This repository contains a Jupyter Notebook analyzing the flu vaccines administered by different pharmacies as part of the NHS seasonal influenza vaccination service.

## Data Source

* **Background**

        The data source contains information on the number, type and cost of flu vaccines administered by community pharmacies as part of the NHS seasonal influenza vaccination advanced service (running September to March each year). The service exists to reduce unplanned hospital admissions and pressure on A&E. The dataset is released for those interested in public spending, delivery of the healthcare service and the role of community pharmacies in the NHS. It was chosen as a real-world dataset of a managable size, to practice exploratory data analysis.

* **Source** 

    December 2025 dataset: https://opendata.nhsbsa.net/dataset/community-pharmacy-adult-seasonal-influenza-vaccination-service-report-pharmacy-contractors/resource/792613ac-7561-4757-8c05-71e850445f04

    Info page: https://opendata.nhsbsa.net/dataset/community-pharmacy-adult-seasonal-influenza-vaccination-service-report-pharmacy-contractors
